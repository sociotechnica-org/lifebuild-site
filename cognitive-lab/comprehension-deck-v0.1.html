01 · the realization

Stations were forms.
They should be lenses on the same thing.

— before

Five disconnected forms

Frame, Comprehend, Sync, Produce, Debrief — each had (or would have had) its own form, its own state, its own JSON.

Debrief reconstructed Frame from memory. Comprehend had no home. Sync was vapor.

"Wall of text" loop: more fields, more forms, less coherence.

— after

One unit, five lenses

There's a unit of work flowing through the whole turn. The station isn't the thing — it's a different way of looking at the thing.

Frame doesn't file a card. Frame sets the course. Every station downstream renders the same course.

02 · the metaphor

Rogaine: an Australian orienteering sport.
Time-boxed score-collection on a map you can't clean.

The shape

  • Hard time budget · 24h is canonical · 30 min late = DNF
  • Map of valued checkpoints · 10–100 points each · pick your own route
  • Pre-event planning window · 2–4 hours with the map · plan under pressure
  • Hash house · central rest point · refuel, re-orient, decide

The lesson

"The course is set so the winning team visits most but not all."

— IRF Rule C2

The signature failure isn't under-ambition.
It's "just one more control" — chasing past the bail-out, hitting the late-penalty cliff.

Elite skill: demote the plan when the plan is no longer correct.

04 · the design call

Frontier, not itinerary.

If a Course pre-assigned items to legs…

  • Determinism. Easy to chart.
  • Loses the "you choose your route" quality.
  • Re-litigated every time the day changes.
  • Becomes a Gantt chart in disguise.

Course names what's reachable this week.

  • Per-leg Frame picks from the frontier.
  • Surprises and emergence land naturally.
  • "Demote the plan" is a normal move, not a failure.
  • The week has shape; the day has freedom.

Author's framing: "Chart your course per turn."

05 · the data model

Three tiers. Schema-flat. Frontier-not-itinerary.

Map — lifetime backlog (existing items + areas) └── Course — a 7-leg arc, ISO-week-stamped (COURSE-2026-W18) ├── theme one line: what this week is for ├── target_outcome how the map looks different by leg 7 ├── frontier[] LAB item IDs reachable this week ├── bail_conditions when do we abandon this Course? ├── legs[] leg slots, filled progressively └── status planning · in-progress · debriefed · archived Leg — one Full Turn (LEG-2026-05-04-A) ├── course_ref parent course id ├── leg_number 1..7 ├── frame_card_id → existing Frame card schema ├── comprehend[] timestamped on-demand notes ├── sync deferred placeholder ├── produce { selected[], bonuses[], notes[] } ├── debrief_card_id → existing Debrief card schema └── changes_to_course writeback to course.frontier on debrief

06 · two metaphors, two tiers

Different cognitive jobs.
Different metaphors.

course / map tier

Hex Map · terrain

Items as hexes. Area accent = biome. Status = fog. P0 = red glow. Frontier = teal halo.

"Where am I in the bigger picture? What's reachable? What's been explored?"

"What am I building this leg? Do I have all the components wired right?"

07 · the design language

Bruner + Kay + Snap Circuits
drives every visual choice from here.

enactive

know where you are · manipulate

Picking, dragging, snapping things into place. Direct, tactile.

iconic

recognize · compare · configure

Glanceable visual states. Color, position, glow. Read in a beat.

symbolic

long chains of reasoning · abstract

Where the lab lived (text, JSON). Now: only when no other mode will do.

"Constructing a diagram is much less difficult than trying to read one."
— Alan Kay (per WS004)

Aspiration: the lab should feel like Snap Circuits, not MS-DOS.
Build the board next to the diagram. See the signal flow. Snap, don't type.

09 · what shipped — course header

One glanceable strip. Top of every workshop.

LEG-2026-05-04-A MUSTS 2/3 BONUS 1 MAP 3/41 in scope in-progress

What it shows

  • Leg ID — which leg is active
  • 7-segment LED bar — book title hook · current lit, prior dim, future ghosted
  • MUSTS x/3 — turns red if you go over cap
  • BONUS x — Frame card's stretch[]
  • MAP x/y in scope — frontier vs. total items
  • Status badge — planning · in-progress · debriefed

When it updates

  • Every time you open a workshop drawer
  • After you save a Frame card (auto-creates leg if needed)
  • After you save a Debrief card (status flips to debriefed)

Empty state when no leg yet: a clickable nudge to open the Course tab.

10 · what shipped — leg view

Leg tab. The Snap Circuit board.

Five vertically-stacked component cards. Signal flows top to bottom.

🔋 power source Frame Linked Frame card's musts + bonuses as chips.
⚡ amplifier Comprehend Newest 3 notes from the leg's comprehend[].
≈ filter Sync Slot present, form deferred (LAB-035).
〰 live signal Produce Selected · bonuses · notes counters.
🔊 output stage Debrief Course held? · caught · changes_to_course summary.

Read-only v0.1. Click-throughs into the underlying forms are queued (LAB-037).

11 · what shipped — debrief rogaine shape

Debrief: from 7 free-text probes
→ 6 fields that write themselves.

— before

  • Subject · Framed · Actual · Diverged · Sustain · Improve · Capacity
  • Free text everywhere. Reconstructed Frame from memory.
  • "Where they diverged" was the thing that did the most work — and it was the same field as everything else.

— after (rogaine shape)

  • Score · auto-derived from leg.frame · you verify, don't fill
  • Caught · what you actually came home with
  • Course held? · radio: as set / different / wrong from start
  • What changed it · only meaningful if not "as set"
  • Better moves · the slot for the future Course Coach
  • Capacity + next · bridge to next leg

Save also writes back to leg.changes_to_course and bumps status → debriefed. Old cards stay readable (legacy fields retained on view).

12 · how it all flows

One spine. Five lenses. Pulled through a turn.

01 Plan Course tab — set theme, target, frontier. Hex map highlights what's in scope.
→
02 Frame Open Frame Workshop. Save a card → Leg auto-created → Course Header lights segment 1.
→
03 Comprehend Mid-leg, drop notes from Course tab. Lands on leg.comprehend[]. Amplifier lights.
→
04 Produce Work the leg. (Ledger UI: deferred — but the slot is real.)
→
05 Debrief Save → Score auto · Course held? · changes_to_course writeback · status flips to debriefed.

The Leg view renders all of this as a single circuit board — same data, iconic shape.
The Course Header rides at the top of every workshop drawer — same data, glanceable strip.

13 · the named future

Course Coach.
Reads legs[] like poker hand histories.

Why it has a slot now

  • Debrief's Better moves field is reserved for it.
  • The Leg wrapper exists so it has something to read.
  • Naming the role keeps the architecture from drifting.

What it would do

  • Cross-leg pattern surfacing (the Push that always overruns, the bonus that never gets touched).
  • Suggest moves for the next leg's Frame.
  • Doesn't decide. Suggests. Author still drives.

Filed as LAB-034. Not built tonight.

"Like online poker coaches — review your hands, name better moves, calibrate over weeks."
— author, design dialog
