03 · hex map v0.2 — biome regions + 4 channels

Stop overloading hue. Use four channels.

The encoding

  • Hue = biome (area accent) — stable identity
  • Luminosity = relevance — 4-state ramp (archived dim → in-frontier bright)
  • Stroke = priority (P0 ring at 2px, second-channeled for color-blind)
  • Motion = attention — single pulse on click + slow ambient breath on the active leg's working set

Items grouped into labeled biome regions. Honors prefers-reduced-motion.

Same items, four signals, no fight.

04 · hex map v0.3 — concentric rings + okabe-ito

Priority becomes spatial.
Not a ring around each hex — a ring of hexes.

P0 anchors the center. P1 expands outward. P2 outermost. Ring position carries priority — the red P0 ring drops entirely.

Color-blind palette

Okabe-Ito 8-color qualitative scheme. Each existing area accent maps to one Okabe-Ito hue. Distinguishable to all common color-vision profiles.

Genus:species hover

Hover any hex → instant tooltip (HTML, not 1-sec native delay): "Frame Workshop: chapter draft". aria-label replaces <title> to suppress the duplicate native tooltip.

Map legend

Below the SVG: each area + its color + count. The regions ARE the legend. Like a real map.

05 · the realization

Snap Circuits ship with a build book.
We were giving you the box without instructions.

"The colors and brightness work quite well. But this giant map is too obtuse. Let's go back to the snap circuit analogy. You don't get a bag full of snap circuits and then wished good luck. You get a book with builds in it. Our first mistake is giving the user positive space rather than negative space. Our second mistake is not giving them a template."
— author, mid-arc

The next move wasn't a better map. It was an empty board, a parts bin, and a build book.

Kay's principle, redirected: "It's easier to build a diagram than read a diagram." Was for our design choices. Now it's for the user's.

06 · build canvas v0.1

An empty board.
A drawer of parts.
Click to place.

7×10 grid. Snap-circuit style.

The mechanic

  • Drawer pick — click an item, takes it "in hand"
  • Cell click — snaps it into place
  • Placed-piece click — action chip (Pick up · Remove · Cancel)
  • Apply template — frontier batch-places in priority order, skipping anything you've already placed
  • Persists on course.build_positions

Deferred to v0.5+

Drag-and-drop. Connections (edges between placed pieces). Sandbox-Course mode. In-lab walk authoring UI.

08 · comprehend signals (Phase 1.5)

Four kinds of comprehension.
Three auto-logged.

What auto-logs

  • note manual capture (already shipped)
  • synthesis status cycle to live or archived
  • deck opening a deck file (matched by DECK_FILE_RE)
  • walk walk start + completion (later in this deck)

The surveillance line

Only acts the user intentionally took and would expect to leave a record. No mouse-tracking, no search-query log, no item-hover. The lab's tone is "you're the director."

Where it surfaces

  • Course view · log below the Hex Map
  • Leg view · Comprehend zone subtitle ("2 notes · 1 synthesis · 3 decks · 1 walk")
  • Comprehend Station · "Where you are" snapshot, last 3 acts (later in this deck)
"If the user would be surprised to see it in a log, don't log it."
— Quenton, Phase 1.5 design dialog

09 · frontier wiring

Frame picker now reads the Course.

— before

Frame's picker showed every LAB item. The architecture said "pick from the frontier." The picker didn't know the frontier existed. The Hex Map and the Frame card disagreed silently.

— after

Picker scopes to the active Course's frontier by default. Toggle to "Full lab" for the deliberate exception. Off-frontier picks tag the chip with a ↗ badge.

Sets up Debrief later: when a leg ends, the off-frontier picks pre-fill changes_to_course.frontier_added. The frontier evolves through deviation, not just declaration.

Empty-frontier auto-flips to "Full lab" with a one-line nudge to set the frontier in the Course view.

14 · the recursion defense

The lab inside the lab.
Without a Comprehend Station inside the Comprehend Station inside…

When ?walk=1 is set

  • Banner injects across the top: "⚑ Walk in progress — close from the Comprehend Station to return to the full lab"
  • Comprehend Station on the floor goes inert (opacity 0.3, pointer-events: none, aria-hidden)
  • saveActiveView + saveCourseHexLens skip writes — iframe nav doesn't bleed to the parent's persisted prefs
  • Iframe carries sandbox="allow-scripts allow-same-origin allow-forms" — closes window.top nav while preserving localStorage

target_route

Walks can boot the iframe directly into the right view + lens via URL query params:

target_route: 'view=course&lens=build'

Saves a wasted "click Course" first step. Allowlist sanitizes the string before injection.

State-mutation warning

Step 0 of any product walk that mutates state warns: "This walk will modify your active Course. Open a fresh Course first if you want a sandbox."
